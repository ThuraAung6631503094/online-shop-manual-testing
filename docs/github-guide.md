1. Open GitHub and create a repository named online-shop-manual-testing under your own account.
2. Choose visibility according to whether you want public portfolio access.
3. Enable Add a README so the repository has an initial commit and branch.
4. Send its repository link in this conversation. ChatGPT can then inspect the repository and upload these files without changing unrelated work.

## Alternative: upload yourself

Extract the ZIP first. Open the new repository and choose Add file → Upload files. Upload the contents inside online-shop-manual-testing, preserving folders, then commit. Do not upload only the ZIP if you want GitHub to render the project documents. If GitHub presents an existing-file conflict for README.md, edit the initial README separately using the prepared text.
